# 🍳 The Odin Project: Recipes

Welcome to my Odin recipe box! This project is part of [The Odin Project](https://www.theodinproject.com/) Foundations Course, where I'm learning the art of web development — one delicious recipe at a time.

## 📖 About This Project

This repo contains a simple recipe website built with pure **HTML**. The goal was to practice fundamental HTML concepts like:

- Page structure and boilerplate
- Headings, paragraphs, and lists
- Links and images
- Multiple interlinked pages

No CSS (yet)! Just good old-fashioned semantic HTML. The design might be simple, but the recipes are full of flavor.

## 🍽️ The Three Naija Dishes

This collection features three iconic Nigerian comfort foods:

### 1. 🫘 **Nigerian Porridge Beans (Ewa Oloyin)**
Creamy, savory beans porridge made with black-eyed peas or honey beans, palm oil, bell peppers, onions, and assorted meat or fish. Pure comfort in a bowl!

### 2. 🍛 **Jollof Rice (Party Jollof)**
The legendary West African party staple! Long-grain rice cooked in a rich, smoky tomato and pepper sauce with onions, thyme, curry, and assorted spices. Fireside debates welcome — Nigerian jollof is simply the best.

### 3. 🍠 **Yam Porridge (Asaro)**
Soft, chunky yam cubes simmered in a flavorful tomato-pepper stew with palm oil, vegetables, and optionally fish or meat. It's sweet, savory, spicy — everything you want in a one-pot meal.



Each recipe includes:
- A mouth-watering photo
- A list of ingredients
- Step-by-step cooking instructions
